# Miki App Store - เว็บแอปพรีเมียมราคาส่ง สไตล์คาเฟ่เบเกอรี่ญี่ปุ่น

เว็บแอปพลิเคชันระบบกดรับบัญชีแอปพรีเมียมราคาส่งอัตโนมัติ 24 ชม. ออกแบบในธีมร้านคาเฟ่เบเกอรี่ญี่ปุ่นโทนอบอุ่น ละมุนตา ไม่แวววาว ปุ่มทรงโค้งมนสไตล์ iOS ปราศจาก Unicode Emoji 100% (Zero Emoji)

---

## ตอบคำถาม: จำเป็นต้องใช้ Supabase ด้วยหรือไม่?

- **ถ้าเปิดรันบนเครื่องตัวเอง (Local Development):**
  - **ไม่ต้องใช้ Supabase ก็ได้** เพราะระบบถูกตั้งค่าเริ่มต้นให้ใช้ **SQLite (`prisma/dev.db`)** ซึ่งพร้อมใช้งานทันทีแบบออฟไลน์ ไม่ต้องสมัครหรือต่ออินเทอร์เน็ต แค่สั่ง `npm run dev` ก็ใช้งานได้เลย

- **ถ้าจะนำขึ้น GitHub แล้วเอาไป Deploy ขึ้นเว็บจริง (เช่น Vercel / Netlify):**
  - **จำเป็น / แนะนำให้ใช้ Supabase (ฟรี):**
    - เนื่องจากเว็บโฮสติ้ง Serverless อย่าง Vercel จะไม่มีฮาร์ดดิสก์ถาวร ไฟล์ฐานข้อมูล SQLite จะถูกรีเซ็ตใหม่ทุกครั้งที่มีการอัปเดตโค้ดหรือเว็บดับ ข้อมูลออเดอร์ เครดิต และสต็อกที่ลูกค้าซื้อจะหาย
    - **Supabase ให้ฐานข้อมูล PostgreSQL ฟรีบนคลาวด์** ข้อมูลจะคงอยู่อย่างปลอดภัยตลอดเวลา และมีหน้าจอจัดการดูข้อมูลตารางที่ใช้งานง่ายมาก

### ขั้นตอนการเชื่อมต่อ Supabase เข้ากับโปรเจกต์ (3 นาทีเสร็จ):
1. สมัครใช้งานฟรีที่ [supabase.com](https://supabase.com) แล้วกด **New project**
2. ไปที่เมนู **Project Settings > Database** เลื่อนลงมาที่หัวข้อ **Connection string**
3. เลือกแท็บ **URI** และคัดลอก Connection String มาใส่ในไฟล์ `.env`:
   ```env
   DATABASE_URL="postgresql://postgres.[YOUR-PROJECT-REF]:[YOUR-PASSWORD]@aws-0-[REGION].pooler.supabase.com:6543/postgres?pgbouncer=true"
   DIRECT_URL="postgresql://postgres.[YOUR-PROJECT-REF]:[YOUR-PASSWORD]@aws-0-[REGION].pooler.supabase.com:5432/postgres"
   ```
4. เปิดไฟล์ `prisma/schema.prisma` แล้วเปลี่ยนบรรทัดที่ 2:
   ```prisma
   datasource db {
     provider = "postgresql" // เปลี่ยนจาก sqlite เป็น postgresql
     url      = env("DATABASE_URL")
     directUrl = env("DIRECT_URL")
   }
   ```
5. สั่งอัปเดตและนำเข้าข้อมูล:
   ```bash
   npx prisma db push
   npm run seed
   ```

## จุดเด่นและฟีเจอร์สำคัญของระบบ

- **หน้าบ้านสไตล์คาเฟ่เบเกอรี่ญี่ปุ่น & ฟีล iOS:**
  - โทนสีครีมอบอุ่น น้ำตาลเข้ม และชมพูพีชละมุนตา
  - ปุ่มกดทุกปุ่มเป็นมุมโค้งมนสูง (High border-radius / Rounded Pill)
  - **มาสคอต PNG เต็มตัว:** แสดงตัวละครโปร่งใสแบบเต็มตัวยืนข้างชื่อร้าน ไม่มีการครอบกรอบวงกลม
  - **บับเบิลข้อความอนิเมชัน:** แสดงจุดไข่ปลา `...` จำลองการกำลังพิมพ์ แล้วเด้งขยายเป็นข้อความทักทายของร้าน
  - **แถบเมนูนำทางสไตล์ iOS (Floating Bottom Dock):** ย้ายเมนูนำทางหลักมาไว้ที่ Dock ด้านล่างหน้าจอ ไม่เบียดหรือทับแถบหัวเรื่องด้านบน และข้อความไม่ตกบรรทัด
  - **ป้ายสถานะร้านจุดเดียว:** แสดงป้าย "เปิดเตาพร้อมส่ง (OPEN)" ทางด้านขวาจุดเดียวชัดเจน
  - **ช่องทางติดต่อแยกโซน:** รวมปุ่ม LINE, Facebook, และ Instagram โค้งมนอย่างเป็นระเบียบ

- **ระบบชำระเงิน & QR Code พร้อมเพย์:**
  - **PromptPay EMVCo แท้:** สแกนจ่ายได้จริง 100% ผ่านทุกแอปพลิเคชันธนาคารในไทย มีการคำนวณ CRC16 Polynomial 0x1021 ถูกต้องตามมาตรฐาน ธปท.
  - **การ์ด 3D พลิกดู QR ธนาคาร:** มีปุ่มกดพลิกการ์ดแบบ 3D หมุนสลับเพื่อดู QR Code ภาพบัญชีปกติที่แอดมินอัปโหลดไว้

- **การสั่งซื้อ & การส่งมอบข้อมูลให้ลูกค้า:**
  - แสดงผลบัญชีที่ได้รับทันทีหลังกดซื้อ (อีเมล, รหัสผ่าน, จอที่ได้รับ, PIN, วันหมดอายุ)
  - **ปุ่มคัดลอกกฎ & วิธีใช้:** สามารถกดคัดลอกเฉพาะกฎการใช้งานและวิธีล็อกอินได้
  - **ปุ่ม One-Click Copy ส่งลูกค้า:** รวบรวมข้อมูลทุกอย่างทั้งบัญชี รหัส และกฎระเบียบ จัดรูปแบบข้อความพร้อมส่งให้ลูกค้าในแชตได้ในคลิกเดียว
  - รองรับปุ่มขอรหัส OTP ผ่าน LINE Official Account ของสินค้านั้นๆ

- **ระบบหลังบ้านผู้ดูแลระบบ (Admin Center):**
  - **แท็บประวัติการตัดสต็อก & รายการคำสั่งซื้อ:** ดูได้ครบถ้วนว่าใครซื้อแอปอะไร ได้อีเมล รหัสผ่าน จอไหน PIN อะไร วันที่ซื้อและวันหมดอายุ
  - **ระบบปรับเครดิตสองทิศทาง:** แอดมินสามารถเลือกโหมด `[+ เพิ่มเครดิต]` หรือ `[- ลด / หักเครดิต]` พร้อมพรีวิวยอดคงเหลือใหม่แบบเรียลไทม์
  - **ปรับแต่งหน้าร้านได้ทั้งหมด:** แก้ไขชื่อร้าน, แท็ก, คำบรรยาย, รูปปก, รูปโลโก้, รูปมาสคอต, คำพูดมาสคอต, ข้อมูลติดต่อ และบัญชีธนาคารได้จากหน้าเว็บทันที
  - **ระบบ Recycle บัญชี:** บัญชีที่หมดอายุจะถูกพักไว้ในสถานะ Servicing เมื่อแอดมินเปลี่ยนรหัสผ่านในแอปจริงแล้ว สามารถกรอกรหัสใหม่และกดดึงกลับเข้าสต็อกพร้อมขายได้ทันที

- **ความปลอดภัยระดับสูง:**
  - ข้อมูลอีเมลและรหัสผ่านสต็อกถูกเข้ารหัสด้วย **AES-256-GCM** เก็บแยก IV และ Tag อย่างปลอดภัย
  - รหัสผ่านผู้ใช้เข้ารหัสด้วย **bcryptjs**
  - จัดการเซสชันด้วย **HTTP-only Cookie (jose JWT)**

## ขั้นตอนการนำขึ้น GitHub

### วิธีที่ 1: ผ่าน Git Command Line
```bash
git init
git add .
git commit -m "feat: Miki App Store complete release with iOS bottom dock and Supabase support"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
git push -u origin main
```

### วิธีที่ 2: ผ่าน GitHub Desktop
1. เปิดโปรแกรม **GitHub Desktop**
2. เลือก **File > Add local repository...**
3. เลือกโฟลเดอร์โปรเจกต์นี้
4. กดปุ่ม **Publish repository** เพื่อนำขึ้น GitHub ของคุณได้ทันที

ไฟล์ที่ไม่จำเป็น (เช่น `.next/`, `node_modules/`, ไฟล์ฐานข้อมูลจำลอง `.db`, และไฟล์ความลับ `.env`) จะถูกกรองออกโดยอัตโนมัติตามไฟล์ `.gitignore` และจะมีไฟล์แม่แบบ `.env.example` ติดขึ้นไปเพื่อให้ผู้อื่นหรือเซิร์ฟเวอร์นำไปใช้งานต่อได้อย่างถูกต้อง

## ขั้นตอนการติดตั้งและรันโปรเจกต์ (Quick Start)

1. ติดตั้ง Dependencies:
   ```bash
   npm install
   ```

2. ตั้งค่าไฟล์ Environment:
   ```bash
   cp .env.example .env
   ```

3. ซิงค์ฐานข้อมูลและสร้างข้อมูลตั้งต้น:
   ```bash
   npx prisma db push
   npm run seed
   ```

4. สั่งรันเว็บเซิร์ฟเวอร์:
   ```bash
   npm run dev
   ```
   เปิดเบราว์เซอร์ไปที่ [http://localhost:3000](http://localhost:3000)

## สแตกเทคโนโลยี (Tech Stack)

- **Framework:** Next.js 16 (App Router + Turbopack)
- **Language:** TypeScript 5
- **Database & ORM:** SQLite / PostgreSQL + Prisma ORM 6
- **Styling:** Tailwind CSS 4 (Warm Bakery Cafe Palette)
- **Icons:** Lucide Icons & Custom SVG (Zero Unicode Emoji)
- **Cryptography:** AES-256-GCM Vault & bcryptjs
